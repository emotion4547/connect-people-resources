# Работа для Всех: руководство по рабочим местам

Сайт: https://rabota-vsem-56.ru. Вход по почте и паролю. Сотрудник видит в меню только разделы, на которые у его роли есть право
(матрица прав настраивается в «Права ролей» у администратора). После входа открывается стартовая страница роли.

| Роль | Стартовая страница | Для чего |
| --- | --- | --- |
| Руководитель | Дашборды | всё: показатели, деньги, сделки, права |
| Менеджер продаж | Сделки | воронка, КП, заказчики, тарифы, план продаж |
| Менеджер объектов | Планирование | заказы, смены, назначения, табели, вахты, документы людей на смене |
| Рекрутёр | Мой день | кандидаты, допуск, документы, активация базы |
| Бухгалтер | Дашборды | начисления, акты и счета, оплаты, выплаты, ДДС, БДР |
| Заказчик | Сегодня | заказ, кто выходит, табели, документы, показатели |
| Исполнитель | Мои смены | отклики, смены, отметка, заработок, реквизиты, аванс |

## Сквозной сценарий (проверка от заказа до денег)

1. **Менеджер объектов:** «Заказы» → новый заказ для заказчика по тарифу → «Принять заказ» (создаются смены).
2. **Менеджер объектов:** «Планирование» → ячейка смены → назначить исполнителей. Если у человека нет действующего обязательного документа,
   система откажет с причиной.
3. **Исполнитель:** «Мои смены» → подтвердить выход → в день смены «Я на месте».
4. **Менеджер объектов:** «Табель» → проверить часы → отправить заказчику.
5. **Заказчик:** «Табели» → подтвердить (или оспорить строку). Без ответа табель подтверждается сам через 48 часов.
6. **Бухгалтер:** «Начисления» появляются сразу после подтверждения → «Документы» → собрать акт и счёт → выставить.
7. **Бухгалтер:** «Оплаты» → загрузить выписку банка (kl_to_1c.txt) → платежи разносятся сами → «Реестры выплат» → собрать реестр,
   подтвердить вторым лицом, провести.
8. **Руководитель:** «Дашборды» — выручка, маржа, укомплектованность; «Деньги» — остатки и разрыв; «БДР» — план/факт.

## Что нового в этапе 3

- **Деньги (ДДС).** Кнопка «Счета» — внести остаток на начало; «Выписка» — загрузка по всем операциям; «Правила» — разнесение по статьям;
  «Календарь» — прогноз на 4 недели с кассовым разрывом; «БДР» — план, факт, отклонения, срезы, копия прошлого года с ростом.
- **Аналитика.** «Дашборды» — вкладки по отделам; «Аналитика» — все показатели с прошлым периодом. Нажмите на число, чтобы увидеть записи.
- **Сделки.** Канбан, «Мой день», КП (печать в PDF), выигрыш создаёт заказчика и тарифы-черновики.
- **Контроль документов.** Реестр сроков, напоминания исполнителям, смены под угрозой (красным в планировании).
- **Вахты.** В карточке заказа «Оформить как вахту»; календарь вахт и свободные места в жилье — в разделе «Вахты».
- **Импорт из Excel.** Шаблон → заполнить → загрузить; перед записью виден итог и причины по каждой строке.

## Выгрузки и печать

Кнопки «В Excel» дают файл `.xlsx`. Для обмена с 1С и шаблонов импорта используется CSV. Печатные формы: табель (кнопка «Печатная форма»),
акты и счета, КП, реестр выплат, ведомости: «Печать / сохранить в PDF» в браузере.

## Если что-то не работает

- Нет раздела в меню — у роли нет права на модуль: администратор открывает «Права ролей».
- Назначение отклоняется — причина в тексте ответа (документ, договор, стоп-лист, пересечение смен, налоговый статус).
- Нет данных на дашборде — проверьте период и что есть подтверждённые табели и начисления.
- Нужна помощь разработчика — записывайте адрес страницы, роль и что именно нажимали.

## Демонстрационная организация

Чтобы дашборды, БДР, ДДС, документы, сделки и вахта было на чём смотреть, создана отдельная организация **«ТЕСТ Демо-организация»**: 4 недели смен
(≈100 смен, 300 назначений, 17 исполнителей), начисления, акты и счета (часть просрочена, один оплачен), табели на разных стадиях, остаток денег и расходы,
план БДР и план продаж, 6 сделок, кандидаты, документы с истекающими сроками (смены под угрозой), вахта на следующую неделю. Тестовые сотрудники и заказчик
получили в ней роли: переключайтесь организацией в левом меню. Рабочие данные это не затрагивает. Скрипт — `deploy/scripts/demo-org.sql`, проверка на
локальной базе — `node scripts/demo-check.mjs`. Убрать демо: «Организации» → выключить «ТЕСТ Демо-организация».
